OJWGAとは？

魔女「おいじぃ」が裄供する5つのミニゲームを遊んで、ポイントを貯めてスコアを伸ばすコレクションじゃ！
複数ユーザーで交代プレイでき、家族や友達とも楽しめるぞい。

🔑 スタートの5ステップ

  1. 左上の 名前表示 をタップ → ユーザー一覧を開く
  2. 「＋ 新しいユーザーを作成」を押し、アイコン・名前を設定
  3. 必要なら パスワード と ヒント を入力（推奨）
  4. 作成完了したらホーム画面へ戻る
  5. 遊びたいゲームカードをタップしてスタート！
✨ ちょっとしたコツ
パスワードは設定したら忘れるなよ！ ヒントに「好きな動物」「誕生日」など、自分だけわかる言葉を書くと安全じゃ。

🏗️ プレス

デス・プレスデスプレス1.png
🏗️ おいじぃのデス・プレス 順位決定戦

4つの足場の中から1つを選ぶ完全運ゲー!選んだ足場にプレス機が落ちてくるかは運次第。生き残るのはたった1人……あなたか?

タイプ:運ゲー プレイ人数:4人(自分+CPU3人) 所要時間:約1〜2分 難易度:易しい 必要スキル:運

📖 ストーリー背景

魔女おいじぃの巨大工場、その地下に潜む「デス・プレスホール」。ここでは生き残った人数分の足場が並び、上空から巨大プレス機が次々と降ってくる。生き残れるのは最後の1人だけ……どこに落ちるかは完全にランダム、運を信じて選ぶのじゃ!

🎯 ゲームの目的

  • 4人(あなた+CPU3体)がそれぞれ足場を1つずつ選ぶ(1つの足場には1人しか入れん)
  • あなたが選んだ足場は必ず確保、CPUは残りの足場にランダム配置
  • プレス機が落ちる足場は完全ランダム。潰された人がそのラウンドの脱落
  • ラウンドごとに足場が1つ減り、最後まで生き残れば 堂々の1位!

🕹️ 操作方法

  • タップ/クリック:足場ボタンを1つ選ぶだけ(キーボード操作なし)
  • 考える時間:制限時間なし、じっくり選んでOK
  • 選んだら魔女がレバーを引いてプレス機落下 → 結果発表
  • あなたが脱落した後は「CPUの対決を見届ける」ボタンで最後まで観戦できる
ℹ️ 完全な運ゲーじゃ
プレス機が落ちる足場はMath.randomで完全ランダム。魔女のセリフや表情にヒントは一切ない。何度でも挑戦して運を試すのじゃ。
🌟 スペシャルタイム:ツイン・プレス
  • 毎日23:00〜23:30に遊ぶとツイン・プレスルールが発動!
  • 1ラウンドに2箇所同時にプレス機が落下する通常よりハードなモードじゃ
  • 残り2人の最終決戦で両方潰れると覇者なしになることも
  • ドキドキ感倍増、運試しに最適な時間帯じゃ

💡 運試しのコツ

① 好きな数字
ラッキーナンバー縛りなど、自分ルールで楽しむと飽きない。
② 端っこ狙い
真ん中より端を選ぶ人が多い。気分で端を狙うのも一手。
③ 23時台狙い
ツイン・プレスの刺激が欲しければ23:00〜23:30に遊ぶべし。
④ 諦めない
4位でもポイントは入る。何度も挑戦して運を蓄積じゃ。
⚠️ 注意点
  • セリフにヒントはない → 読みすぎると疲れるだけ。割り切って楽しもう
  • ツイン・プレス時は一気に2人脱落することも → 順位変動が激しい
  • チャレンジモードなら4位でも+10pt → 負けても損はない

🏭 大爆発

大爆発大爆発2.png
🏭 おいじぃ魔女大爆発 複雑なる工場

3D工場の中で危険なスイッチを避けながらサバイバル!どれが爆発スイッチかは完全ランダム。10秒以内に選んで運を試せ!

タイプ:運+時間制限 プレイ人数:4人 所要時間:約2〜3分 難易度:中 必要スキル:運 決断力

📖 ストーリー背景

おいじぃの大工場には、床にたくさんのスイッチが並んでいる。その中の1つが爆発スイッチで、押してしまえば一巻の終わり……。どれが危険かは完全にランダム、10秒以内に選んで運を試せ!

🎯 ゲームの目的

  • 4人(あなた+CPU3体)が順番にスイッチを1つ押していく
  • 爆発スイッチを引いた人がその場で脱落!
  • 全員セーフならスイッチをリセットして仕切り直し
  • 最後まで残れば 1位

🕹️ 操作方法

  • タップ/クリック:3D空間のスイッチを直接押す(キーボード操作なし)
  • 10秒以内に選ばないと即爆発で脱落!
  • 自分の番が来たら10秒カウントダウン開始。魔女の煽りに惑わされるな
  • スイッチを選ぶと魔女がスイッチ目前へズームアップ。ドキドキの2.5秒間
ℹ️ スイッチの数は生存者で変わる
4人いる時はスイッチ5個、3人なら4個、2人なら3個。生存者+1個のスイッチが並ぶ。全員セーフならリセットして仕切り直しじゃ。
ℹ️ 完全な運ゲーじゃ
爆発スイッチはMath.randomで完全ランダムに決まる。パイプやランプの色・形にヒントは一切ない(工場の配管はただの飾り)。セリフや表情も演出じゃ。

💡 生き残るコツ

① 10秒を味方に
焦る必要はないが、10秒経つと即爆発。時計を見ながら余裕を持って選ぶべし。
② CPUを見届ける
自分より前のCPUが押したスイッチは除外される。残り選択肢から選ぼう。
③ リセット待ち
全員セーフでリセットされればラウンド延長=生存確率UP。安全な順番を狙う。
④ 直感勝負
ヒントはない。迷ったら直感で選んでサッと終わらせるのが一番じゃ。
⚠️ やりがちなミス
  • 10秒放置 → 即爆発で脱落。タイマーを忘れるな
  • パイプやランプを読もうとする → ヒントはない、時間の無駄
  • 派手な演出にビビる → 爆発位置は見た目と無関係
  • ズーム演出中に焦る → 結果は選んだ時点で決まってる、落ち着いて

🌀 猛追

猛追 DX猛追3.png
🌀 おいじぃ魔女の猛追 DX

魔女に追いかけられる60秒間のサバイバル!迷路を逃げ続けよ!唯一の本格アクションゲームじゃ。

タイプ:アクション プレイ人数:4人(自分+AI3体) 所要時間:約1〜2分 難易度:難 必要スキル:反射神経 空間認識

📖 ストーリー背景

魔女おいじぃの怒りに触れ、巨大な迷路に閉じ込められたあなたとAI3体。背後から猛スピードで迫る魔女から、60秒間逃げ切れるか?ミニマップを駆使し、知能で生き残れ!

🎯 ゲームの目的

  • 魔女に捕まらないように 60秒間逃げ続ける
  • 長く生き残るほど高順位(生存時間で順位決定)
  • 60秒完全生存で1位確定(複数生存なら同着1位)
  • 捕まったら脱落、ただし生存時間に応じてポイントは入る

🕹️ 操作方法(超詳細)

端末操作
📱 スマホ画面右下のDパッド(▲◀▶▼)かスワイプで移動
📱 タブレット同上、画面が大きい分操作しやすい
💻 PC↑↓←→ または WASDキー

🗺️ ミニマップの使い方

  • 画面右上に表示されるレーダーマップ
  • 🟥 赤い点 = あなた
  • 🟪 紫の点 = 魔女(凍結中は灰色)
  • 🟩 緑 / 🟨 黄 / 🩵 シアン = 他のCPU3体
  • 🟦 青 = ⚡スピードアイテム、🟨 黄 = ❄️フリーズアイテム
  • 魔女が近づいてくる方向を常にチェック!
  • 慣れてきたら遠くから魔女の動きを予測して進路決定

⚡ アイテムを活用せよ

  • ⚡ スピード:一定時間自分の移動速度アップ(全身に⚡オーラ)
  • ❄️ フリーズ:魔女を3秒間凍結!追跡が止まる大チャンス
  • アイテムは全部で5個(スピード3・フリーズ2)。拾い合いになるぞい
ℹ️ 魔女は時間で加速する
時間が経つほど魔女の移動速度が上がっていく(0.09 + 経過秒×0.0045)。序盤は逃げやすく、終盤は追い詰められる。終盤ほどアイテムが鍵じゃ。

🏃 迷路サバイバル戦術

① 視界を切る
角を曲がって魔女から見えなくする。これが逃走の基本。
② 円を描いて回る
広い場所ではぐるぐる回って魔女を消耗させる。
③ AIを盾にする
魔女のターゲットを他のAIに移すよう動く。
④ フェイント走り
急に方向転換して魔女を惑わせる。曲がり角で有効。
⑤ 端を活用
迷路の端は逃げ場が少ないが、魔女の動きも限定される。
⑥ ミニマップ先読み
マップを見て、魔女が来る前に進路変更。
🌟 上級者テクニック
  • 真っ直ぐ逃げず、ジグザグに動いて当たり判定を避ける
  • 魔女が近づいたら直角に曲がる。動きを予測されにくい
  • 追い詰められたら大きく回り込む。Uターンで魔女を引き離す
  • 残り時間10秒は安全地帯でひたすら時間稼ぎ
  • 音を出してプレイすると魔女の足音で位置がわかる
  • キーボード操作はスワイプより素早く反応できる
⚠️ やりがちなミス
  • 魔女から目を離さずに走り続ける → 壁にぶつかる
  • 端に張り付く → 逃げ場がなくなり詰む
  • ミニマップを見ない → 待ち伏せされる
  • 同じ方向にずっと走る → 予測されやすい
  • 慣れる前にチャレンジ挑戦 → 大量ポイントを逃す

🎚️ 難易度別プレイ感

  • 初心者:30秒生存できれば上出来。慣れることを優先
  • 中級者:45〜60秒生存を狙う。ミニマップ活用必須
  • 上級者:60秒完全生存+AIを陥れて1位確定

魔女おいじぃの本社ビル前。入口には3つの扉が並び、その奥のどれか1つに魔女が待ち構えている。魔女のドアを選ぶとぶっ飛ばされてハート1つ失う。3つのハートが尽きるまで何ラウンド耐えられる?

🎯 ゲームの目的

  • 3つのドア(左・真ん中・右)から1つ選ぶ。各ドア定員2人
  • 2つは安全(お菓子)、1つは魔女のドア。引くとハート1つ失う
  • ハートは1人3個。3回引かれたら脱落
  • 4人中最後まで残れば 1位

🕹️ 操作方法

  • タップ/クリック:左・中央・右の3つのドアから1つを選ぶ(キーボード操作なし)
  • 5秒以内に選ばないと即脱落!タイマーに注意
  • 魔女のドアは毎ラウンドランダムに入れ替わる
  • CPUはカウントダウン中に各自勝手にドアを選んで移動する
ℹ️ 完全な運ゲーじゃ
魔女のドアは毎ラウンドランダムに入れ替わる。扉の揺れ・笑い声・影・セリフにヒントは一切ない。純粋な3分の1の運勝負じゃ。

💡 ハートを守るコツ

① 5秒を死守
時間切れはハート関係なく即脱落。必ず5秒以内に選ぼう。
② 定員2人を狙う
各ドア2人まで。CPUが集まったドアを避けて空いてるドアを選ぶ手もある。
③ ハート3個=3回挑戦
魔女を引いても3回までは死なん。焦らず何度も運試しできる。
④ CPUの脱落待ち
CPUが先に魔女を引いて脱落することも。生き残りを狙う。
⚠️ やりがちなミス
  • 5秒放置 → 即脱落。カウントダウンを見忘れるな
  • 扉の揺れやセリフを探す → ヒントはない、時間の無駄
  • 毎回同じドア → 魔女はランダムなので意味はないが、気分的に
  • ハート0ギリギリまで粘る → 油断して時間切れ脱落に注意

👨‍👩‍👧 保護者の方へ

お子さんが安全に楽しく遊べるよう、保護者専用の設定が用意されているぞい。

🛡️ 保護者コントロールでできること

設定 → 保護者コントロールから開ける。時間・休憩・夜間・パスワード保護を総合管理する画面じゃ。

  • ⏰ 1日のプレイ時間制限:1分単位で上限設定(0=無制限〜1440分)
  • ⚠️ 制限前の警告:何分前に警告するか設定(0〜60分)
  • ☕ 休憩タイマー:一定間隔で休憩を促す(間隔と休憩時間を設定)
  • 🌙 夜間ロック:指定時刻〜指定時刻は遊べなくする
  • 🔒 パスワード保護:初期化・バックアップ・制限超過時に保護者パスワード必須(各切替)
  • ⏱️ プレイ時間リセット:今日のプレイ時間を0に戻す

⏰ 時間制限が迫ると？

  • 設定した警告分数前にホーム画面のバッジでお知らせ
  • ホームに残りプレイ時間と夜間ロックまでがバッジ表示される
  • 制限に達するとタイムロック画面が全面に出る

🌙 夜間ロック・休憩タイマー

  • 夜間ロック:「ロック開始時刻・解除時刻」を設定すると、その時間は遊べん
  • 休憩タイマー:「休憩を促す間隔」と「休憩時間の長さ」を設定すると、定期的に休憩を催促
  • 時計ウィジェットで夜間ロックまでの残り時間も表示できる
ℹ️ タイムロック画面について
時間切れ・夜間ロック時に出る画面は再読み込みしても閉じられん。ホームに戻ることもできず、保護者パスワードで時間を延長するしか解除方法はない。子どもが勝手に抜け出せない仕組みじゃ。

⏱️ 時間を延長したいとき

  1. タイムロック画面の「🔐 解除ボタン(保護者用)」を押す
  2. 保護者パスワードを入力
  3. 延長する分数を入力(+5/+10/+15/+30/+60分のボタンもあり)
  4. 「延長する」で続きを遊べる

🔐 保護者パスワードの設定方法

  1. 設定メニュー → 保護者モードを開く
  2. 「保護者パスワード設定」をタップ
  3. 4桁以上の数字 or 英数字でパスワード入力
  4. ヒントも必ず入力(忘れた時用)
  5. 確認のため再入力 → 確定
